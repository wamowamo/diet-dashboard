# diet-dashboard webinput v12

ホーム画面を最新の承認イメージに合わせて再設計。

主な変更:
- 現在体重 / 計画達成度を横並び
- 計画達成度は数値表示のみ（0〜200%バーは無し）
- 計画達成度 = (開始体重-現在体重) / (開始体重-今日の予定体重) × 100
- 直近7日をスマホで4+3ではなく2列ベースの2段表示にして可読性を優先
- kgは数字と同じ行に固定
- 目標設定カードと体重推移グラフをホームに配置
- 記録・履歴・グラフ・設定はv11を維持

GitHubでは `index.html` のみ上書きすればOK。Apps Scriptの変更は不要。
