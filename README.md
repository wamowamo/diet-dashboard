# diet-dashboard v9（Web入力版）

Googleフォームを使わず、GitHub Pages のWeb画面から直接体重を入力し、
Googleスプレッドシートをデータベースとして使う版です。

## 画面
- 進捗
- 体重入力
- 履歴
- グラフ
- 設定

## 朝／夜の自動選択
初期値は 12:00 切替です。
- 11:59まで → 朝
- 12:00以降 → 夜

入力画面の「朝」「夜」はいつでもタップして変更できます。
設定画面から切替時刻も変更できます。

## 初回のApps Script設定

1. Apps Script の `Code.gs` を、このZIPの `apps-script/Code.gs` に丸ごと置き換える
2. 保存
3. 関数の選択で `setupWebApp` を選んで「実行」
4. 実行ログに表示される **8桁の書き込みPIN** を控える
5. 「デプロイ」→「デプロイを管理」→鉛筆→「新しいバージョン」→デプロイ

既存のウェブアプリURLはそのまま使えます。

## GitHub

リポジトリ `diet-dashboard` の直下へ以下をアップロード／上書き:
- `index.html`
- `manifest.webmanifest`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

古い `history.html` や `style.css` 等は残っていても新しい `index.html` からは使いません。

## PIN

閲覧は今まで通り誰でも可能です。
記録・修正・削除・設定変更だけPIN認証にしています。

最初の保存時にPINを聞かれます。
「この端末に保存」をONにすると、以後は通常PIN入力不要です。

## スプレッドシート

Webからの記録は既存の非表示シート `フォームの回答 1` に追記します。
Googleフォームは今後使わなくても構いません。

履歴・ダッシュボードの集計は、Apps Scriptが `フォームの回答 1` を直接集計します。
