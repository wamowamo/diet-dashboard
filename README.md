# diet-dashboard-webinput v17

v16をベースにしたスマホ表示・朝夜切替時刻の修正版です。

## v17の変更

- iPhone幅で「直近7日間の体重」が必ず **4枚 + 3枚の2行** になるよう修正。
  - v16に残っていた7枚目の `grid-column: 1 / 2` 指定が、4+2+1の3行になる原因でした。
- 記録タブの日付横の現在時刻は表示しません。
- 記録タブの長い朝／夜自動選択説明文は表示しません。
- 記録タブのヘッダーにあった重複する自動選択説明も非表示にしました。
- フロント側でも朝／夜切替時刻を `HH:mm` に正規化し、旧キャッシュに1899年の日付文字列が残っていても12:00等として扱えるようにしました。
- iOS/GitHub Pagesで古いHTMLが残りにくいよう、キャッシュ抑制用metaを追加しました。
- v16の80kg実測達成による第2目標への切替・指数カーブ前倒し仕様は維持しています。

## Apps Scriptについて

今回、Code.gs側にも修正があります。別途 `Code-v17.gs` をApps Scriptへ反映してください。

- Web設定の `morningCutoff` がGoogle Sheets上で時刻型になっていても `HH:mm` として返すよう修正。
- 設定保存時は先にセルを文字列書式へしてから書き込み、`12:00` が1899年の日付型へ変換されるのを防止。
- APIキャッシュキーをv10へ更新。

## GitHubへアップロード

GitHub Pages側は `index.html` を差し替えてください。アイコン類は変更ありません。
