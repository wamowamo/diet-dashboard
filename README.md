# diet-dashboard-webinput v18

v17をベースに、iPhoneの直近7日表示と進捗カードを修正した版です。

## v18の変更

1. **直近7日間をスマホで必ず4枚 + 3枚の2行に固定**
   - 1〜4枚目を1行目、5〜7枚目を2行目へ明示配置しています。
   - 390px幅・320px幅を想定したCSSです。
2. **予定体重の表示を小数点第2位へ変更**
   - 進捗画面と履歴画面、CSVの予定体重を2桁表示に変更。
   - 指数関数の内部計算は丸めず、従来どおり高精度のままです。
3. **計画達成度の注意文を削除して縦幅を詰める**
   - 「このまま体重が変わらない場合…」の赤い注意欄を削除しました。
4. **「先行」を緑表示**
   - 先行時の文字色を緑、背景を淡い緑に変更しました。

v17で導入した朝／夜切替時刻の正規化、80kg達成時の第2目標への切替などは維持しています。

## Apps Script

v18ではCode.gsの変更はありません。v17のCode.gsをそのまま使用してください。

## GitHubへアップロード

GitHub Pages側は `index.html` を差し替えてください。アイコン類は変更ありません。
